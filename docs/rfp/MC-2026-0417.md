# 提案依頼書(RFP)

**RFP 番号:** MC-2026-0417
**発行元:** Meridian Components, Inc.
**発行日:** 2026年4月17日
**提案提出期限:** 2026年5月8日 17:00(米国中部時間)

---

## 1. はじめに

Meridian Components は、産業用オートメーション部品(センサー、アクチュエーター、コントローラー、回路基板、電源装置)を取り扱う中堅ディストリビューターであり、サンフランシスコ、ロンドン、東京に倉庫を構えて事業を展開しております。年間売上高は約960万ドルです。

このたび当社は、**既存の在庫管理ダッシュボードのモダナイズおよび機能拡張**を担っていただけるベンダーを募集いたします。現行システムは2024年に前任ベンダーにより納品されたもので、稼働はしているものの未完成の部分が残っています。応募各社が正確に見積もりを行えるよう、本 RFP パッケージにはソースコードおよび前任ベンダーの引き継ぎ資料を同梱しております。

## 2. 背景と現状

当社のオペレーションチームは、各倉庫の在庫水準、受注、サプライヤー支出、需要予測を把握するために Web ベースのダッシュボードを日常的に利用しています。現行システムの状況は以下のとおりです。

- Vue/Python による Web アプリケーションとして社内ホスティングで稼働
- 在庫、受注、支出の主要ビューをカバー
- **Reports モジュールに既知の欠陥**があり、前任ベンダーは契約終了までに解消していない
- オペレーションチームが要望している機能のうち、複数が未実装(§3 参照)
- **自動テストが一切整備されておらず**、IT チームが変更の承認に慎重にならざるを得ない状態

前任ベンダーのドキュメントは限られています。選定されたベンダーには、オンボーディングの一環として独自にアーキテクチャレビューを実施していただくことを想定しています。

## 3. 業務範囲

選定されたベンダーには、以下の項目を納品していただきます。各項目は当社の優先順位順に記載しています。

### 3.1 必須項目

| # | 要件 | 内容 |
|---|---|---|
| R1 | **Reports モジュールの改修** | 既存の Reports ページの欠陥をすべて調査し、解消すること。当社チームはフィルターの挙動、国際化対応の不備、データパターンの不整合など、少なくとも8件の問題を記録している。 |
| R2 | **発注推奨機能** | 新規機能。現在の在庫水準、需要予測、およびオペレーターが指定する予算上限に基づいて発注を推奨する Restocking ビューを追加すること。 |
| R3 | **ブラウザテストの自動化** | 主要なユーザーフローに対するエンドツーエンドのテストカバレッジを整備し、当社 IT チームが今後の変更を安全に承認できるようにすること。 |
| R4 | **アーキテクチャドキュメント** | 当社 IT への引き継ぎに耐える現状アーキテクチャの概要資料を納品すること。形式はベンダーの裁量に委ねる。 |

### 3.2 希望項目(評価対象とするが必須ではない)

| # | 要件 | 内容 |
|---|---|---|
| D1 | **UI のモダナイズ** | 現在の標準に沿ってビジュアルデザインを刷新すること。 |
| D2 | **国際化対応** | 残りのモジュールへ i18n 対応を拡張すること(現在、東京倉庫のスタッフは英語表示のみの画面で業務を行っている)。 |
| D3 | **ダークモード** | オペレーターが選択可能なテーマ。複数の倉庫フロア端末が低照度環境で運用されている。 |

## 4. 提案書の要件

提案書には以下を含めてください。

1. **エグゼクティブサマリー**:当社のニーズに対する理解と提案アプローチ(1ページ以内)
2. **技術アプローチ**:§3 の各項目にどう取り組むか(前提条件があれば併記)
3. **関連実績**:類似案件の実績
4. **スケジュール**:フェーズ分けした納品計画
5. **価格**:固定報酬、または上限額付きの T&M

なお、最終候補に残ったベンダーには、簡潔なケイパビリティ・プレゼンテーション(スライド10〜15枚)の提出をお願いする場合があります。

## 5. 評価基準

| 評価項目 | 配点比率 |
|---|---|
| 技術アプローチおよび要件理解 | 40% |
| 関連実績 | 25% |
| スケジュール | 20% |
| 価格 | 15% |
