Meridian Components ワークショップ — 生成レポート一式
=====================================================

すべて単一 HTML です。ブラウザで開くだけで閲覧できます。
（日本語フォントは Google Fonts から取得するため、初回はネットワーク接続が
　あると綺麗に表示されます。オフラインでも内容は読めます）

## ファイル

01-capabilities-deck.html
    ケイパビリティ・プレゼンテーション（12枚）
    操作: ← → / Space でページ送り、F で全画面、P で印刷

02-architecture.html
    アーキテクチャドキュメント（要件 R4 の納品物）
    ※ 技術的負債の一覧を含みます。ワークショップ参加者に配布する場合は
      答えが含まれる点にご注意ください

03-progress-report.html
    プロジェクト進捗報告書（フェーズ3完了時点）

04-workshop-retrospective.html
    ワークショップ振り返り報告書
    ※ assets/ 内の画像を参照します。同じ階層に展開してください

05-workshop-guide-participant.html
    参加者用ガイドブック
    → 参加者に配布してください。課題の答えは記載していません

06-workshop-guide-instructor.html
    講師用ガイドブック
    → ★参加者には配布しないでください。課題の答えを含みます

07-R1-defect-matrix.md
    講師用参考情報
　　 案件: Meridian Components 在庫ダッシュボード の既存Bug例

assets/
    04 の報告書が参照するスクリーンショット 12 点

## 注意

- 04 を閲覧する場合は assets/ フォルダを同じ階層に置いてください
- 06（講師用）と 02（アーキテクチャ文書）は答えを含みます
