## 補足:根本原因について

個別の14件は、いずれも独立した不具合ではない。

他の6ビューが `useFilters` / `api.js` / `useI18n` / `utils/currency.js` / Composition API という共通の枠組みに乗っているのに対し、**`Reports.vue` だけがそのいずれにも接続されていない**。D-01、D-03、D-04、D-07、D-08、D-09 は、すべてこの一点から派生している。

したがって修正方針は、14件を個別に潰すのではなく、**既存6ビューと同じ枠組みへ接続すること**とする。枠組みに乗せた時点で、上記6件は同時に解消される。

残る D-02、D-05(バックエンド)、D-06、D-10、D-11、D-12、D-13、D-14 は個別対応となる。

## 対応順序(案)

| 段階 | 対象 | 内容 |
|---|---|---|
| 1 | D-02、D-05 | バックエンドのフィルター対応と、四半期判定の年度依存の解消 |
| 2 | D-07 | `api.js` へのエンドポイント登録 |
| 3 | D-09 | Composition API への移行(この時点で D-11、D-13、D-14 も併せて解消) |
| 4 | D-01 | `useFilters` との接続と `watch` の追加 |
| 5 | D-03、D-08、D-06 | `utils/currency.js` への統一と入力検証の追加 |
| 6 | D-04 | 辞書への `reports` セクション追加と `t()` への置き換え |
| 7 | D-10、D-12 | `computed` 化と `:key` の修正 |

段階1〜2でバックエンドと API 層を整えてから、段階3でフロントエンドを枠組みに乗せる。以降は枠組みの上での作業となるため、手戻りが生じにくい。
